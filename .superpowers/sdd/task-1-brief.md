# Task 1: Backup and Create Integration Branch

**Goal:** Prepare git environment for migration work by creating a clean integration branch.

## Requirements

- Check current git status to ensure clean working directory
- Create integration branch named `feature/integrate-staff-iq-web`
- Verify branch was created successfully
- Create an empty commit to mark the start of this work

## Steps

1. Check current git status
2. Create the integration branch: `git checkout -b feature/integrate-staff-iq-web`
3. Verify branch was created with `git branch`
4. Create initial commit: `git commit --allow-empty -m "feat: start staff_iq_web migration to ayanlab-hrm-ui"`

## Success Criteria

- Currently on branch `feature/integrate-staff-iq-web`
- Branch is clean and ready for work
- Initial commit created with appropriate message
