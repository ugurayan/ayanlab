# ayanlab-<APP>-mobile

Flutter mobile uygulaması. `scripts/mobile-template` golden template'ten
`scripts/scaffold-mobile.sh <app>` ile üretilir.

## Çalıştırma

```bash
flutter pub get
flutter run
```

## Notlar

- Tüm veriler mock; API bağlantısı yok.
- 11 dil (en, zh, hi, es, fr, ar, bn, pt, ru, tr, ur); `ar` ve `ur` RTL.
- Şablonu değiştirmek için `scripts/mobile-template` düzenleyip scripti yeniden
  çalıştırın (hedef klasör silinip yeniden oluşturulur).
